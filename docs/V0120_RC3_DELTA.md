# V0.12.0 RC3 變更與驗收範圍

RC3 僅修正法規記憶體快照新鮮度及 `tlr` 選用依賴，並同步候選版本、回歸測試與安裝驗收。不增加大型功能，也不授權公開發布。

## 法規快照

`OfficialLawProvider` 的記憶體資料保存獨立的資料集取得時間、解析驗證時間、到期時間與內容摘要。`load`、精確查詢、關鍵詞搜尋及引用解析共用此到期檢查。有效區間為取得時間（含）至到期時間（不含）；快取命中不得滑動續期。

來源的 `fetched_at`、`verified_at`、`expires_at` 繼承資料集觀察，不因再次組合來源物件而重設。當次讀取記錄 `lookup_checked_at`；網頁內容複核成功另記 `webpage_verified_at`，兩者都不延長資料集期限。下載或網頁複核跨過期限時，不回傳可升格的來源或證據。

到期或明示強制更新時先撤銷舊快照；HTTP、逾時、壓縮檔或結構解析失敗，不回退至舊資料，也不把失敗當作查無。下一次呼叫必須重新取得。健康探測不更新快照生命週期。注入時鐘及既有 `now` 參數僅為受管 Python 呼叫／合成測試使用，未新增 MCP 呼叫端設定時間的權限。

既有「尚有效的結構化來源，選用網頁複核暫不可用時附警告」政策保持不變；不能因此延長期限。內容摘要僅供完整性識別，不是數位簽章，也不保證官方上游已即時更新全部資料。法規時點適用性、全域召回完整度與法律結論正確性不屬於本修正的證明範圍。

## 選用依賴與安裝

`tlr` 額外依賴補上 `truststore>=0.10`。發布閘門分別以全新環境安裝基礎 wheel 與僅含 `[tlr]` 的 wheel，不得預先裝入 `dev`／`live` 來掩蓋漏列依賴。TLR-only 安裝同時在 Python 3.11 與 3.12 驗證。

安裝冒煙測試使用隔離直譯器、套件版本及模組實際安裝位置檢查，並執行 CLI 健康診斷及 MCP stdio 初始化／工具列舉。TLR-only 路徑建立真正的系統憑證 SSL context，再以模擬 HTTP 傳輸執行 TLR adapter；不使用憑證、不送真實查詢，也不聲稱這是外部服務的連線可用性測試。日誌只保留測試摘要，不輸出原始 doctor JSON。

## 合成回歸

覆蓋期限內重用、期限邊界、更新後內容變更、更新失敗重試、強制更新失敗、搜尋與引用解析更新、網頁複核成功／失敗不得續期、I/O 中途到期、取得與驗證時間區分、時鐘回撥、健康探測、無效期限與不含時區的時鐘，以及 TLR 依賴宣告。

兩項既有儲存快取整合測試原以一微秒的來源期限製造過期；新提供者會正確拒絕在下載期間已過期的來源。因此改為先取得有效合成來源，再明確令儲存快取關聯到期，保留重新查證成功／失敗與不得重用的全部斷言；不放寬正式新鮮度檢查，也不修改不可變來源。

套件與 MCP 身分為 `0.12.0rc3`，既有 RC1／RC2 標籤、審查與驗收文件保持歷史身分。完整 CI 與安裝閘門須在 RC3 的確切提交重新執行；先前 RC2 綠燈不作為 RC3 的測試結果。保存期限、清除政策、候選／證據分離與最終答案驗證不變。
