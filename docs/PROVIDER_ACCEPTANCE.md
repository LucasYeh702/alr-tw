# 提供者替換、故障與資料用途驗收

適用：v1.0.0。查閱日期：2026-09-14。

## 共用矩陣

| 情境 | 結果及證據 |
|---|---|
| 正常官方來源＋同次研究回執 | `test_v090_provider_conformance.py` 驗證可用來源、證據與回執一致才授予資格。 |
| 有界空集合／未覆蓋期間 | 分開 scoped absence 與未知；無 coverage 不宣稱不存在。歷史試行範圍外回報 unsupported。 |
| timeout、rate limit、部分結果、未知年份、身分異常、官方回查失敗 | `test_runtime_conformance_matrix.py` 對官方／相容候選／TLR 三種身分跑相同輸入；不得核准答案或全域查無。 |
| 候選來源替換 | 沿用既有 candidate port；候選不能提交可信 source，`official_only` 不需外部候選服務。 |
| receipt／source／privacy 不符 | 既有 conformance 與 receipt adapter 測試拒絕，不用其他來源掩蓋信任失敗。 |
| 本機與遠端快取 | `test_remote_pack.py` 對相同固定包的精確命中／未命中使用同一建立來源流程，結果一致且不是 official。 |
| 跨研究、跨請求、快照或內容替換 | 遠端驗證要求隨機 nonce、run、canonical identity、snapshot、完整包及 MAC 一致；不符即拒絕。 |
| 敏感診斷 | doctor 不回傳儲存路徑；遠端端點及金鑰不出現在設定序列化，發布端錯誤只回固定代碼。 |

矩陣驗證契約與受控故障，不冒充對所有第三方服務的可用性保證。Coverage v2 與來源／回執維持單一真值，未新增另一套授權層。

## 用途矩陣

TLR 文件以固定提交 [f5f9b969](https://github.com/aa0101181514/tw-legal-rag/blob/f5f9b969c4e100876a4cfa6b0b3432d4777dbf3b/TERMS.md) 為查閱基準。
程式碼授權與 API／語料使用條款分開，不從舊版 client 授權推定 API 也同樣授權。

| 用途 | TLR 託管 API／語料 | 官方或部署者資料包 |
|---|---|---|
| 個人、研究、內部企業、專業執業 | 條款列入允許用途；仍受公開端點與速率限制約束。 | 依實際來源授權及資料政策；逐筆官方核對不等於取得所有再利用權。 |
| 向第三人提供以 API／語料為主要價值的服務 | 需另行書面約定。 | 對外部署前另核對來源、範圍、個資與再散布條件。 |
| 大量匯出、鏡像、再散布 | 需另行書面約定。 | 本套件不內附第三方 corpus；資料製作與配送由有權操作者負責。 |
| 模型訓練或微調 | 需另行書面約定。 | 不因可下載就自動認定可訓練；逐項確認。 |

[中文法律資料下載](https://data.gov.tw/dataset/18289) 列示政府資料開放授權條款第 1 版；
這是該資料集的標示，不延伸宣稱所有官方網站頁面或附件具有同一授權。
本輪沒有鏡像 TLR、訓練模型或對外託管。官方歷史文本、函釋頁面與本機領域試行包的來源可用性驗收另列，未自行替資料提供者授權。
