# ALR-TW v0.11.0 版本說明

## 新增

- 有界歷審檢查：`inspect_judgment_lineage` 可對同一研究中已驗證的裁判，
  讀取 TLR 記錄的上下級審候選，再逐件回查官方正文，分類上訴駁回、維持、
  廢棄發回與廢棄改判。查無上級審不推論裁判確定，主文分類不等於見解比較。
- 行政函釋候選召回：TLR provider 支援行政函釋與稅務函釋，保留發文字號、
  機關、日期與命中片段；正式證據仍須經部署端接入的官方公法資料驗證。
- 裁判長全文閱讀：TLR provider 支援有界分頁、命中片段、全文總字數、
  截斷狀態與續讀位置；外部全文仍維持候選身分。
- 可選唯讀本機裁判資料層：透過明示設定接入既有相容資料提供者，支援候選
  搜尋、符合檢查條件的 catalog-bound 快取，以及官方來源回查。

## 說明更新

- 資料層可由部署者選用 TLR、`mcp-taiwan-legal-db` 或其他相容法律資料服務；
  前端取得的候選可透過 `client_assisted` 提交，ALR-TW 持續負責來源與證據驗證。
- 更新三語 README、工具契約與來源說明，區分候選召回、官方驗證、歷審主文
  分類與尚未執行的前後審見解比較。
