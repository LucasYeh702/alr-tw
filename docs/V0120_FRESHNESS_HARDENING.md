# v0.12.0 法規快照新鮮度補強

法規記憶體快照保存資料集取得、解析驗證、到期時間與內容摘要。
有效區間為取得時間（含）至到期時間（不含），快取命中不得滑動續期。

來源繼承資料集時間；lookup_checked_at 與 webpage_verified_at 僅記錄觀察，
不延長期限。到期或強制更新先撤銷舊資料；下載、解析或更新失敗不得回退。
I/O 途中到期時，不回傳可升格來源或證據。健康探測不更新快照生命週期。

注入時鐘只供受管 Python 呼叫與合成測試，未新增 MCP 呼叫端時間權限。
摘要不是數位簽章；本修正不保證上游即時更新、完整歷史法、法律適用正確性，
也不是所有 provider 的快照生命週期重寫。引用解析沿用失敗回空清單的既有 API，
空清單不得視為法源不存在。

測試涵蓋期限內重用、到期更新、失敗重試、強制更新失敗、網頁複核、I/O 中途
到期、時鐘回撥與健康探測。儲存快取整合測試明確令合成快取關聯到期，不再
依賴一微秒期限的下載競速，也不修改不可變來源或放寬正式新鮮度檢查。

隔離安裝測試分開驗證基本 wheel 與 TLR-only wheel，使用真實 TLS context
和模擬 HTTP 傳輸。公開 CI 設定覆蓋 Python 3.11／3.12；本機實跑範圍另列，
不得把工作流程設定存在寫成 CI 已執行。
